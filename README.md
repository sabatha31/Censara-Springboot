# Censara

AI-powered personal finance platform that helps users understand their financial health through analytics, predictions, and intelligent recommendations.

## Features

- User authentication
- Income & expense tracking
- Financial dashboard
- AI-generated insights
- Savings predictions
- Financial health scoring
- Interactive charts
- REST API backend

## Tech Stack

Backend
- Java
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Maven

Analytics
- Python
- Pandas
- Scikit-learn

Frontend
- JavaFX
- CSS

Tools
- Git
- GitHub
- Docker

## Architecture

JavaFX Client
        ↓
Spring Boot REST API
        ↓
PostgreSQL Database
        ↓
Python Analytics Engine
        ↓
Predictions & Insights
